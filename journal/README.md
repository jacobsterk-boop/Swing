# Trading Journal & Memory

Persistent knowledge base so each session starts with full context instead of
cold. **Read these files at the start of every trading session.**

| File | What's in it |
|---|---|
| `account.md` | The tradeable account, holdings, autonomy grants, constraints |
| `environment.md` | Tooling/infra learnings — what works, what's broken, workflows |
| `playbook.md` | Trading rules & lessons learned (accumulated wisdom) |
| `watchlist-setups.md` | Active setups being watched, with entry triggers |
| `sessions/` | Dated session logs — decisions made and why |

Also see `../TRADING_POLICY.md` (the guardrails) and `../universe.txt` (the
43-name deep-dive universe).

**Maintenance rule:** update these as we learn. When a setup triggers or
invalidates, move it out of `watchlist-setups.md` into the session log with the
outcome. Keep `account.md` / `environment.md` current when facts change.
